## Ideas that run through the whole app

Four rules explain most of how the app behaves. They are worth reading once.

**History is never rewritten.** Anything that changes over time is recorded with the date it changed
from, not edited in place: a salary rate, a pay schedule, a card's annual fee, a budget line's
amount, a loan balance. Change one of these and the months before it keep the figures you actually
lived through. See [Budget](budget.md#when-an-amount-changes) and [Cards](cards.md#when-a-fee-changes).

**Every number can be traced.** Hover almost any figure and it shows the formula that produced it —
`$300.00 ÷ 12 months`, `47.346 shares × $84.44`. If a number looks wrong, the hover usually says why.

**Nothing is invented.** The app never fills in a figure it does not have. A dash means "not
recorded", not "zero". Where it has to estimate, it says so.

**You only enter a thing once.** A budget line knows its category and often its label, so assigning
it during an import fills the rest in. A card knows its fee, so it can create the budget line for it.

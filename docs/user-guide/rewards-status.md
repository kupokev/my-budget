# Rewards status

**What it answers:** where am I against hotel and airline status, and what would it take to get there?

This is the read-only view of the programs you set up on [Loyalty programs](loyalty-programs.md) and
the cards on [Cards](cards.md).

## Status progress

For each program: your current tier, the next one, and every path to it. A tier is rarely reachable
only one way — nights, stays, base points, card spend, or simply holding a card — so the app shows
each path with how far along you are.

Where a path is behind the pace needed to finish the year in time, it says what monthly spend would
close the gap, and lists the alternatives.

## Earning

What each card has earned this year, at your cents-per-point, and what that is worth.

## A note on point values

The app does not pretend a point has one true value. A cents-per-point figure is whatever you decide
it is worth, set per program or per card. To work out whether a specific booking is worth points or
cash, use [Points vs cash](points-vs-cash.md) — that compares one real booking rather than relying on
an average.

## Heads-up

Anything worth acting on appears in the rewards heads-up: a tier falling behind, a spend threshold
that will not be reached at the current rate, a card benefit expiring unused this quarter.

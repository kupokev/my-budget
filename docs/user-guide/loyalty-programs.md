# Loyalty programs

**What it answers:** what tiers exist, and how do I reach them?

Set up IHG, Hilton, Delta or anything else here; see where you stand on
[Rewards status](rewards-status.md).

## Tiers and paths

A tier usually has several routes: nights, stays, base points, card spend, or simply holding a card.
Add each one as a **path**, and the app tracks all of them and tells you which is closest.

## Status is flexible on purpose

Real programs do not behave tidily, so the model does not assume they do:

- Status **carries year to year** rather than resetting cleanly.
- Status in one program can come from **holding a card tied to a different program**.
- A card can grant perks with **no program behind it at all**.

If a card grants status in a program it is not tied to, add a **hold card** path on that program.

## Point values

Cents per point, set per program and overridable per card. This is what "rewards value" is measured
in across the app. It is your estimate, not a published figure — and for a specific booking, use
[Points vs cash](points-vs-cash.md) instead of an average.

# Reports

**What it answers:** how does this year compare with last?

## Year over year

Spending by category, this year against last, with the change. Use it to find what actually moved
rather than what feels like it moved.

## Net worth

The same history as the [Wealth dashboard](wealth-dashboard.md) chart, as figures you can read
month by month.

## Export

Writes your data out as CSV for a spreadsheet. This is for analysis — to back the app up properly,
use **Export budget** on [Settings](settings.md), which writes the whole database in one file.

# Roadmap

| Phase | Scope |
| --- | --- |
| 1. Core ledger | Income sources, accounts, bills with card/account assignment, monthly actuals, transfer needs, card dashboard, plus a basic home view (bills due, transfer needs this pay period) so the landing screen exists from the start |
| 2. Calculators | Paycheck estimator + what-if, HSA planner, loan amortization |
| 3. Rewards | Earn rules, thresholds, loyalty programs, progress, card recommendations |
| 4. Import & history | CSV/OFX import, historical import, goals linked to metrics, YoY reports |
| 5. Build-out | Investments (INV-1–6), alerts, full home dashboard (rewards progress, alerts, AI summary), local AI (AI-1/AI-2), 1099 tax set-aside, receivables, dividends, crypto, home improvements |

Desktop app (Photino on Linux) first throughout; the Android app is additive once the shared UI is stable.
Keep this in sync with the detailed functional requirements as phases complete or reorder.

# Roadmap

| Phase | Scope |
| --- | --- |
| 1. Core ledger | Income sources, accounts, bills with card/account assignment, monthly actuals, transfer needs, card dashboard, plus a basic home view (bills due, transfer needs this pay period) so the landing screen exists from the start |
| 2. Calculators | Paycheck estimator + what-if, HSA planner, loan amortization, bonus withholding, editable tax tables (built 2026-09-26; stub verification pending) |
| 3. Rewards | Earn rules, thresholds, loyalty programs, progress, card recommendations, card catalog, spend plan with gaps (built 2026-09-26; real card spend and program activity still to enter) |
| 4. Import & history | CSV/OFX import with institution layouts, categorization rules, bill/card sync, spending dashboard, goals linked to metrics, YoY, net worth, CSV export (built 2026-09-26) |
| 5. Build-out | Built 2026-09-26: investments with DRIP/gains/wash sales, alerts, full home dashboard, local AI (tool-calling, off until Ollama is configured), 1099 set-aside, receivables, rainy-day fund, home/vehicle values. Remaining: reimbursables, profit sharing, crypto, home improvements, bill notes, calendar view |

Desktop app (Photino on Linux) first throughout; the Android app is additive once the shared UI is stable.
Keep this in sync with the detailed functional requirements as phases complete or reorder.
